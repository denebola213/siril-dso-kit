# flat_panel_qc — フラット光源のムラを回転差分で測る

フラットパネル／拡散板（iPad、EL パネル、トレーシングペーパー等）のムラが、フラットに
どれくらい写り込むかを実測します。「パネルが悪いのか、光学系が悪いのか」を切り分けるための道具です。

## 原理

同じ光学系・フォーカス・フィルタで、**光源だけを 180 度回転**（または大きく平行移動）させて
スタック済みフラットを2枚撮ります。

- 光学系の減光（周辺減光・ダスト）は両者で同じ
- 光源のムラだけが回転する

なので、2枚の比の**平滑成分**が 1 からどれだけずれるかが、光源ムラの実効量になります。

## 使い方

```bash
python3 flat_panel_qc.py A.fit B.fit
python3 flat_panel_qc.py A.fit B.fit --pedestal 500 --smooth 64 --grid 8
```

| オプション | 既定 | 意味 |
|---|---|---|
| `--pedestal` | 0 | バイアス／オフセット（ADU）。バイアス減算済みなら 0 |
| `--smooth` | 64 | 比を平滑する窓 [px] |
| `--grid` | 8 | 表示グリッド数 |

出力は比の平滑成分の標準偏差・最大・最小（％）と、グリッドごとの値です。

## 判定の目安

| 最大偏差 | 判定 |
|---|---|
| < 0.5% | 良好 |
| 0.5 – 1% | 実用 |
| > 1% | 拡散不足。紙を1枚足す、パネルを近づける、距離を稼ぐ |

## 制約

- 2次元 FITS（NAXIS=2）のみ。Bayer 生のモザイクは可、カラー合成済みは不可
- BITPIX 8 / 16 / 32 / -32 / -64 に対応。astropy 不要（numpy のみ）
- 2枚の形状が一致していること
- 回転中心のずれは平滑窓より小さくすること（中心がずれると偽のムラとして出ます）
